CORREÇÕES PARA O BOOTCAMP

Substitua estes arquivos preservando os caminhos a partir da pasta BootCampProject:

1. pytest.ini
2. gateway/src/controllers/auth_controller.py

Motivos:
- A suíte passa a rodar em série por padrão, evitando interferência entre testes que compartilham o mesmo Mockserver.
- O login converte o ID da API de Usuários para uuid.UUID antes de gravar a sessão no banco.

IMPORTANTE: o arquivo gateway/database/database.sql do seu projeto já inclui a tabela `session`, mas o PostgreSQL só executa esse SQL quando o volume do banco nasce.

Se os bancos contêm apenas dados descartáveis de desenvolvimento/teste, rode na pasta BootCampProject:

    docker compose down -v
    docker compose up -d --build --wait
    pytest

ATENÇÃO: `docker compose down -v` apaga os volumes dos quatro bancos deste projeto. Faça backup antes caso precise preservar dados.

Os testes não foram executados nesta sessão porque o ambiente de análise não tem Docker nem os serviços locais nas portas 3000–3003 e 1080. O arquivo Python corrigido passou pela verificação de sintaxe.
